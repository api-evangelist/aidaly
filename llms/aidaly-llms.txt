# Aidaly

> Aidaly is a Miami, Florida home care company that trains, employs and pays family members as
> professional caregivers, so households can draw on Medicaid, Medicare and private benefit dollars for
> care they were already giving unpaid. It runs a software-enabled care agency on its own aidalyOS
> platform and operates in South Florida, Arizona and Michigan, with Colorado and Massachusetts announced.

Generated by API Evangelist from this repository's apis.yml and probe artifacts. Aidaly does not publish an
llms.txt of its own — https://www.aidaly.com/llms.txt returned HTTP 404 on 2026-09-14.

IMPORTANT FOR AGENTS: Aidaly has no public API. There is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, MCP server, agent card or SDK on any host Aidaly controls. Do not attempt to call
api.aidaly.com — it does not resolve. The only machine-reachable surfaces are the public marketing website
and a credentialed web application for staff. Family caregivers and care recipients interact with Aidaly
through an eligibility application and a mobile app, not through an interface an agent can drive.

## Products and services

- [Aidaly Care](https://aidaly.com/aidaly-care): The family caregiver offering. An all-in-one mobile app
  for clock-in/clock-out with "seamless, insurance-required visit verification" (EVV), visit notes, pay
  tracking and care plans, backed by an integrated clinical team.
- [AidalyHQ](https://aidaly.com/hq): A credentialed web platform "run on aidalyOS" used by supervising
  nurses and care operations for supervisory visit documentation. Access is requested from
  operators@aidaly.com. Not a public application.
- [Learning Studio](https://aidaly.com/learning-studio): Caregiver training and content library, also the
  company's article archive.
- [Provider network](https://aidaly.com/provider-network): The Aidaly care-team nurse network.
- [State pay rate guide](https://aidaly.com/family-caregiver-pay-rate-guide): State-by-state guide to what
  family caregivers can be paid.
